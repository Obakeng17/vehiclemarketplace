# Bucks Auto Group - Vehicle Marketplace

A car dealership web app where customers can browse vehicles, book test drives and apply for financing, and admins can manage the stock and bookings.

## Tech used
- Java 21
- Spring Boot
- Spring Security
- Thymeleaf
- MySQL
- HTML, CSS, JavaScript
- Gmail SMTP (for emails)

## Features
- Home page and About Us page
- Vehicle listings page
- Test drive booking with a booking success page
- Financing page
- Admin dashboard
- Admin can add, edit and manage vehicles
- Admin can view bookings
- Image upload for vehicles
- Email notifications

## How to run
1. Install Java 21 and MySQL
2. Create a database called `vehiclemarketplace`
3. Open `src/main/resources/application.properties` and put in your own MySQL username and password
4. In the same file, put in your own Gmail address and a Gmail app password for the email settings
5. Run the project from your IDE, or use `mvn spring-boot:run`
6. Open http://localhost:8080 in your browser
